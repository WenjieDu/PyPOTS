PyPOTS (dibaca "Pie Pots") adalah toolkit Python sumber terbuka untuk analisis deret waktu, yang menawarkan **lebih dari 50 model dan metode dengan API terpadu** untuk imputasi, peramalan, klasifikasi, pengelompokan, deteksi anomali, dan pembelajaran representasi. PyPOTS dirancang untuk deret waktu dunia nyata, termasuk yang memiliki nilai hilang.

Deret waktu bukanlah sistem yang mendasarinya, melainkan kumpulan pengamatan terhadap sistem tersebut. Karena keterbatasan pengukuran dan pengambilan sampel, deret waktu dunia nyata pada dasarnya merupakan pengamatan parsial: variabel terukur hanya menangkap aspek tertentu dari sistem, pengamatan dikumpulkan pada interval diskret dan mungkin tidak teratur, serta beberapa pengukuran mungkin hilang.

**Tidak teramati tidak berarti tidak ada. Pengamatan parsial adalah hal yang lazim, bukan pengecualian.**

Kami memandang deret waktu dunia nyata sebagai **deret waktu teramati sebagian (Partially-Observed Time Series, POTS)**. Dari perspektif ini, pemodelan deret waktu pada dasarnya mempelajari sistem yang mendasari dan dinamikanya dari pengamatan parsial. PyPOTS dibangun berdasarkan filosofi ini untuk memungkinkan analisis terpadu deret waktu dunia nyata.

## ❖ Fitur utama

- **Dukungan multitugas:** imputasi, peramalan, klasifikasi, pengelompokan, deteksi anomali, dan pembelajaran representasi dalam satu toolkit.
- **Dukungan bawaan untuk nilai hilang:** model yang memperhitungkan nilai hilang dapat belajar langsung dari deret waktu tidak lengkap tanpa imputasi sebelumnya.
- **API terpadu:** antarmuka pelatihan dan prediksi yang konsisten memudahkan eksperimen dan perbandingan model.
- **Katalog model yang kaya:** lebih dari 50 model dan metode, termasuk pendekatan klasik, pembelajaran mendalam, model berbasis LLM, dan model fondasi deret waktu (TSFM).
- **<a href="https://landscape.pytorch.org/?item=modeling--specialized--pypots"><img src="https://pypots.com/figs/misc/pytorch.svg" width="26px" align="center">PyTorch Ecosystem</a>:** PyPOTS dibangun di atas PyTorch dan tercantum dalam PyTorch Landscape.
- **Akselerasi perangkat keras:** CPU dan GPU NVIDIA, pelatihan multi-GPU melalui PyTorch DataParallel dan presisi campuran otomatis untuk model yang mendukungnya.
- **Pengelolaan data fleksibel:** data dalam memori dan pemuatan sesuai kebutuhan dari berkas HDF5.
- **Optimasi hiperparameter:** penyetelan model dengan [Optuna](https://github.com/optuna/optuna).
- **Penelitian yang dapat direproduksi:** kumpulan data, simulasi nilai hilang, prapemrosesan terstandar, dan alat evaluasi dalam ekosistem.
- **Arsitektur yang dapat diperluas:** komponen modular dan templat standar untuk mengintegrasikan algoritme baru.

## ❖ Instalasi

PyPOTS memerlukan Python 3.10 atau lebih baru dan tersedia di [PyPI](https://pypi.org/project/pypots/) dan [Anaconda](https://anaconda.org/conda-forge/pypots). Lihat [panduan instalasi](https://docs.pypots.com/en/latest/install.html) untuk persyaratan dependensi dan lingkungan.

Pilih **satu** metode instalasi berikut sesuai lingkungan Anda. Perintah pemutakhiran hanya diperlukan jika PyPOTS sudah terpasang.

**Opsi 1: pip (disarankan)**

```bash
pip install pypots
# Untuk memperbarui: pip install pypots --upgrade
```

**Opsi 2: Conda**

```bash
conda install conda-forge::pypots
# Untuk memperbarui: conda update conda-forge::pypots
```

**Opsi 3: Docker**

```bash
docker run -it --name pypots wenjiedu/pypots
```

Tekan Ctrl-P lalu Ctrl-Q untuk melepaskan koneksi tanpa menghentikan kontainer. Jalankan `docker attach pypots` untuk menyambung kembali.

**Opsi 4: kode sumber terbaru di main (mungkin memuat perubahan yang belum dirilis)**

```bash
pip install https://github.com/WenjieDu/PyPOTS/archive/main.zip
```

## ❖ Penggunaan

### Mulai cepat

Contoh imputasi SAITS mandiri ini menggunakan data sintetis dan tidak memerlukan unduhan kumpulan data. Bentuk input adalah `(n_samples, n_steps, n_features)`, dengan nilai hilang direpresentasikan sebagai `NaN`.

```python
import numpy as np
from pypots.imputation import SAITS

# Membuat deret waktu sintetis dengan nilai hilang
rng = np.random.default_rng(42)
X = rng.normal(size=(16, 24, 8)).astype(np.float32)
X[rng.random(X.shape) < 0.1] = np.nan
train_X, test_X = X[:12], X[12:]

# Menginisialisasi model imputasi SAITS
model = SAITS(
    n_steps=24, n_features=8,
    n_layers=2, d_model=64, n_heads=4,
    d_k=16, d_v=16, d_ffn=128,
    epochs=2, device="cpu",
)
# Melatih model
model.fit({"X": train_X})

# Mengimputasi data uji
imputed_X = model.impute({"X": test_X})
print(imputed_X.shape)  # (4, 24, 8)
```

<summary><b>Tampilkan contoh imputasi PhysioNet2012 dengan SAITS:</b></summary>

``` python
import numpy as np
from pygrinder import calc_missing_rate
from benchpots.datasets import preprocess_physionet2012
data = preprocess_physionet2012(subset='set-a',rate=0.1) # Our ecosystem libs will automatically download and extract it
train_X, val_X, test_X = data["train_X"], data["val_X"], data["test_X"]
print(train_X.shape)  # (n_samples, n_steps, n_features)
print(val_X.shape)  # samples (n_samples) in train set and val set are different, but they have the same sequence len (n_steps) and feature dim (n_features)
print(f"We have {calc_missing_rate(train_X):.1%} values missing in train_X")
train_set = {"X": train_X}  # in training set, simply put the incomplete time series into it
val_set = {
    "X": val_X,
    "X_ori": data["val_X_ori"],  # in validation set, we need ground truth for evaluation and picking the best model checkpoint
}
test_set = {"X": test_X}  # in test set, only give the testing incomplete time series for model to impute
test_X_ori = data["test_X_ori"]  # test_X_ori bears ground truth for evaluation
indicating_mask = np.isnan(test_X) ^ np.isnan(test_X_ori)  # mask indicates the values that are missing in X but not in X_ori, i.e. where the gt values are

from pypots.imputation import SAITS  # import the model you want to use
from pypots.nn.functional import calc_mae
saits = SAITS(n_steps=train_X.shape[1], n_features=train_X.shape[2], n_layers=2, d_model=256, n_heads=4, d_k=64, d_v=64, d_ffn=128, dropout=0.1, epochs=5)
saits.fit(train_set, val_set)  # train the model on the dataset
imputation = saits.impute(test_set)  # impute the originally-missing values and artificially-missing values
mae = calc_mae(imputation, np.nan_to_num(test_X_ori), indicating_mask)  # calculate mean absolute error on the ground truth (artificially-missing values)
saits.save("save_it_here/saits_physionet2012.pypots")  # save the model for future use
saits.load("save_it_here/saits_physionet2012.pypots")  # reload the serialized model file for following imputation or training
```

## ❖ Katalog model

Tabel berikut mencantumkan model dan metode yang diimplementasikan dalam PyPOTS, diurutkan berdasarkan tahun publikasi, beserta tautan daftar tunggu Time-Series.AI. Setiap ✅ bertautan mengarah ke contoh Python mandiri khusus tugas. Sel kosong menunjukkan bahwa implementasi terkait belum tersedia.

Model bertanda `🧑‍🔧` telah diadaptasi untuk menangani nilai hilang secara eksplisit. Bergantung pada tugasnya, adaptasi ini menggunakan embedding dan strategi pelatihan yang memperhitungkan nilai hilang, termasuk rekonstruksi pengamatan dan imputasi bermasker (ORT + MIT) yang diperkenalkan oleh [SAITS](https://arxiv.org/abs/2202.08516)[^1]. ## ❖ Ekosistem PyPOTS

Selamat datang di semesta kopi PyPOTS! Ekosistem kami terinspirasi oleh proses menyeduh kopi, dengan setiap pustaka memiliki peran berbeda dalam analisis deret waktu.

<a href="https://github.com/WenjieDu/TSDB">
    <img src="https://pypots.com/figs/pypots_logos/TSDB/logo_FFBG.svg" align="left" width="140" alt="TSDB logo"/>
</a>

👈 Kumpulan data adalah biji kopi kami, dan kumpulan data POTS adalah biji yang tidak lengkap. [Time Series Data Beans (TSDB)](https://github.com/WenjieDu/TSDB) memudahkan pemuatan kumpulan data deret waktu publik. Kunjungi repositorinya untuk daftar terbaru.

<a href="https://github.com/WenjieDu/PyGrinder">
    <img src="https://pypots.com/figs/pypots_logos/PyGrinder/logo_FFBG.svg" align="right" width="140" alt="PyGrinder logo"/>
</a>

👉 [PyGrinder](https://github.com/WenjieDu/PyGrinder) menggiling biji kopi menjadi tidak lengkap dengan menyimulasikan nilai hilang. Pustaka ini mendukung ketiga mekanisme yang didefinisikan oleh Rubin[^13], yaitu MCAR (hilang secara acak sepenuhnya), MAR (hilang secara acak), dan MNAR (hilang tidak secara acak). Tambahkan nilai hilang sintetis dengan satu baris kode.

Sejumlah proyek penelitian menggunakan dan mengutip PyPOTS. Jelajahi [penelitian yang mengutip atau menggunakan PyPOTS](https://scholar.google.com/scholar?as_ylo=2022&q=%E2%80%9CPyPOTS%E2%80%9D&hl=en).

### Penelitian terkait

- **[SAITS](https://doi.org/10.1016/j.eswa.2023.119619)** (ESWA 2023, lebih dari 1.000 sitasi): proyek penelitian yang melahirkan PyPOTS. Implementasi asli imputasi deret waktu berbasis self-attention menjadi fondasi basis kode PyPOTS.
- **[TSI-Bench](https://arxiv.org/abs/2406.12747)** (pracetak arXiv 2024): Tolok ukur terstandar untuk imputasi deret waktu yang mencakup 34.804 eksperimen, 28 algoritme, dan 8 kumpulan data dalam beragam kondisi kehilangan data. Repositori kode: [Awesome_Imputation](https://github.com/WenjieDu/Awesome_Imputation).
- **[Deep Learning for Multivariate Time Series Imputation: A Survey](https://doi.org/10.24963/ijcai.2025/1187)** (IJCAI 2025): taksonomi metode imputasi, toolkit, dan arah penelitian.
- **[HELIX](https://openreview.net/forum?id=FN20iuPnEU)** (ICML 2026 Spotlight): identitas yang dapat dipelajari dan sintesis lintas dimensi untuk imputasi deret waktu.
- **[End-to-End Learning for Partially-Observed Time Series with PyPOTS](https://doi.org/10.1145/3770855.3816470)** (KDD 2026, tutorial praktik): alur kerja dari persiapan data dan pemodelan multitugas hingga evaluasi serta integrasi model kustom. [Materi tutorial](https://pypots.com/events/KDD2026Tutorial/).

## ❖ Kontribusi

Kami menyambut kontribusi peneliti, insinyur, dan pengguna:

- **Model baru:** tinjau [kriteria penerimaan](https://docs.pypots.com/en/latest/faq.html#inclusion-criteria) dan gunakan templat khusus tugas (misalnya, [imputasi](https://github.com/WenjieDu/PyPOTS/tree/main/pypots/imputation/template)).
- **Perbaikan bug dan fitur:** laporkan masalah yang dapat direproduksi atau usulkan perbaikan melalui [GitHub Issues](https://github.com/WenjieDu/PyPOTS/issues).
- **Dokumentasi dan contoh:** tingkatkan tutorial, dokumentasi API, contoh penggunaan, dan terjemahan.
- **Pengujian:** tambahkan uji regresi untuk meningkatkan keandalan dan reproduksibilitas.
- **Keamanan:** laporkan kerentanan secara privat sesuai [SECURITY.md](https://github.com/WenjieDu/PyPOTS/blob/main/SECURITY.md).

Sebelum mengajukan pull request, kami menyarankan untuk mengaktifkan [pre-commit](https://pre-commit.com/) pada klon lokal agar perubahan Anda diformat dan diperiksa secara otomatis:

```bash
pip install pre-commit
pre-commit install
```

Hook dijalankan secara otomatis setiap kali Anda melakukan commit. Jika hook mengubah berkas, tinjau perubahan tersebut, tambahkan kembali ke staging area, lalu lakukan commit lagi. GitHub CI tetap memeriksa linting dan pemformatan dengan Ruff meskipun Anda tidak memasang hook. Lihat [panduan pengembang](https://docs.pypots.com/en/latest/dev_getting_started.html#using-pre-commit) untuk informasi lebih lanjut.

Kontributor diakui pada [halaman kontributor GitHub](https://github.com/WenjieDu/PyPOTS/graphs/contributors), [situs PyPOTS](https://pypots.com/about/#volunteer-developers), dan catatan rilis jika relevan. Harap patuhi [kode etik](https://github.com/WenjieDu/PyPOTS/blob/main/CODE_OF_CONDUCT.md).

Jika PyPOTS bermanfaat, pertimbangkan memberi bintang pada repositori agar orang lain menemukannya. Lihat juga [afiliasi pengguna kami](https://pypots.com/users/).
