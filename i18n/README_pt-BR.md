PyPOTS (pronuncia-se "Pie Pots") é uma caixa de ferramentas Python de código aberto para análise de séries temporais, com **mais de 50 modelos e métodos com APIs unificadas** para imputação, previsão, classificação, agrupamento, detecção de anomalias e aprendizado de representações. Foi projetada para séries temporais do mundo real, inclusive aquelas com valores ausentes.

Uma série temporal não é o próprio sistema subjacente, mas um conjunto de observações desse sistema. Devido às limitações inerentes à medição e à amostragem, séries temporais reais são essencialmente observações parciais: as variáveis medidas capturam apenas alguns aspectos do sistema, as observações são coletadas em intervalos discretos e possivelmente irregulares, e algumas medições podem estar ausentes.

**Não ser observado não significa necessariamente não existir. A observação parcial é a regra, não a exceção.**

Concebemos séries temporais reais como **séries temporais parcialmente observadas (Partially-Observed Time Series, POTS)**. Nessa perspectiva, a modelagem consiste fundamentalmente em aprender o sistema subjacente e sua dinâmica a partir de observações parciais. O PyPOTS se baseia nessa filosofia para viabilizar a análise unificada de séries temporais reais.

## ❖ Principais recursos

- **Suporte a múltiplas tarefas:** imputação, previsão, classificação, agrupamento, detecção de anomalias e aprendizado de representações em uma única ferramenta.
- **Suporte nativo a valores ausentes:** modelos que consideram a ausência de dados podem aprender diretamente com séries incompletas, sem imputação prévia.
- **APIs unificadas:** interfaces consistentes de treinamento e previsão, facilitando experimentos e comparações.
- **Catálogo abrangente:** mais de 50 modelos e métodos clássicos, de aprendizado profundo, baseados em LLM e modelos fundacionais de séries temporais (TSFM).
- **<a href="https://landscape.pytorch.org/?item=modeling--specialized--pypots"><img src="https://pypots.com/figs/misc/pytorch.svg" width="26px" align="center">PyTorch Ecosystem</a>:** o PyPOTS é construído sobre PyTorch e está presente no PyTorch Landscape.
- **Aceleração por hardware:** CPU, GPU NVIDIA CUDA e NPU Ascend; treinamento em múltiplos dispositivos via PyTorch DistributedDataParallel (DDP), CUDA DataParallel e precisão mista automática para modelos compatíveis. Consulte o [guia de aceleração](https://docs.pypots.com/en/latest/install.html#acceleration) para a configuração e as limitações.
- **Tratamento flexível de dados:** dados em memória e carregamento sob demanda de arquivos HDF5.
- **Otimização de hiperparâmetros:** ajuste de modelos com [Optuna](https://github.com/optuna/optuna).
- **Pesquisa reprodutível:** conjuntos de dados, simulação de valores ausentes, pré-processamento padronizado e ferramentas de avaliação no ecossistema.
- **Arquitetura extensível:** componentes modulares e templates padronizados para integrar novos algoritmos.

## ❖ Instalação

O PyPOTS requer Python 3.10 ou superior e está disponível no [PyPI](https://pypi.org/project/pypots/) e no [Anaconda](https://anaconda.org/conda-forge/pypots). Consulte o [guia de instalação](https://docs.pypots.com/en/latest/install.html) para detalhes sobre dependências e requisitos de ambiente.

Escolha **apenas um** dos métodos de instalação abaixo, de acordo com seu ambiente. Os comandos de atualização só são necessários se você já tiver o PyPOTS instalado.

**Opção 1: pip (recomendada)**

```bash
pip install pypots
# Para atualizar: pip install pypots --upgrade
```

**Opção 2: Conda**

```bash
conda install conda-forge::pypots
# Para atualizar: conda update conda-forge::pypots
```

**Opção 3: Docker**

```bash
docker run -it --name pypots wenjiedu/pypots
```

Pressione Ctrl-P e depois Ctrl-Q para se desconectar sem parar o contêiner. Para reconectar, execute `docker attach pypots`.

**Opção 4: código-fonte mais recente em main (pode incluir alterações ainda não lançadas)**

```bash
pip install https://github.com/WenjieDu/PyPOTS/archive/main.zip
```

## ❖ Uso

### Início rápido

Este exemplo independente de imputação com SAITS usa dados sintéticos e não exige o download de conjuntos de dados. A entrada tem formato `(n_samples, n_steps, n_features)`, com valores ausentes representados por `NaN`.

```python
import numpy as np
from pypots.imputation import SAITS

# Gerar séries temporais sintéticas com valores ausentes
rng = np.random.default_rng(42)
X = rng.normal(size=(16, 24, 8)).astype(np.float32)
X[rng.random(X.shape) < 0.1] = np.nan
train_X, test_X = X[:12], X[12:]

# Inicializar um modelo de imputação SAITS
model = SAITS(
    n_steps=24, n_features=8,
    n_layers=2, d_model=64, n_heads=4,
    d_k=16, d_v=16, d_ffn=128,
    epochs=2, device="cpu",
)
# Treinar o modelo
model.fit({"X": train_X})

# Imputar o conjunto de teste
imputed_X = model.impute({"X": test_X})
print(imputed_X.shape)  # (4, 24, 8)
```

<summary><b>Exibir um exemplo de imputação com SAITS no PhysioNet2012:</b></summary>

``` python
import numpy as np
from pygrinder import calc_missing_rate
from benchpots.datasets import preprocess_physionet2012
data = preprocess_physionet2012(subset='set-a',rate=0.1) # Our ecosystem libs will automatically download and extract it
train_X, val_X, test_X = data["train_X"], data["val_X"], data["test_X"]
print(train_X.shape)  # (n_samples, n_steps, n_features)
print(val_X.shape)  # samples (n_samples) in train set and val set are different, but they have the same sequence len (n_steps) and feature dim (n_features)
print(f"We have {calc_missing_rate(train_X):.1%} values missing in train_X")
train_set = {"X": train_X}  # in training set, simply put the incomplete time series into it
val_set = {
    "X": val_X,
    "X_ori": data["val_X_ori"],  # in validation set, we need ground truth for evaluation and picking the best model checkpoint
}
test_set = {"X": test_X}  # in test set, only give the testing incomplete time series for model to impute
test_X_ori = data["test_X_ori"]  # test_X_ori bears ground truth for evaluation
indicating_mask = np.isnan(test_X) ^ np.isnan(test_X_ori)  # mask indicates the values that are missing in X but not in X_ori, i.e. where the gt values are

from pypots.imputation import SAITS  # import the model you want to use
from pypots.nn.functional import calc_mae
saits = SAITS(n_steps=train_X.shape[1], n_features=train_X.shape[2], n_layers=2, d_model=256, n_heads=4, d_k=64, d_v=64, d_ffn=128, dropout=0.1, epochs=5)
saits.fit(train_set, val_set)  # train the model on the dataset
imputation = saits.impute(test_set)  # impute the originally-missing values and artificially-missing values
mae = calc_mae(imputation, np.nan_to_num(test_X_ori), indicating_mask)  # calculate mean absolute error on the ground truth (artificially-missing values)
saits.save("save_it_here/saits_physionet2012.pypots")  # save the model for future use
saits.load("save_it_here/saits_physionet2012.pypots")  # reload the serialized model file for following imputation or training
```

## ❖ Como citar o PyPOTS

O PyPOTS foi apresentado pela primeira vez no [workshop MiLeTS da KDD 2023](https://kdd-milets.github.io/milets2023/). Se você o utilizar em sua pesquisa, cite o [artigo da ferramenta](https://arxiv.org/abs/2305.18811v2).

```bibtex
@article{du2023pypots,
title = {{PyPOTS: A Python Toolkit for Data Mining on Partially-Observed Time Series}},
author = {Wenjie Du},
journal = {SIGKDD MiLeTS Workshop},
url = {https://arxiv.org/abs/2305.18811v1},
year = {2023},
}
```

```bibtex
@article{du2025pypots,
title = {{PyPOTS: A Python Toolkit for Machine Learning on Partially-Observed Time Series}},
author = {Wenjie Du and Yiyuan Yang and Linglong Qian and Jun Wang and Qingsong Wen},
journal = {arXiv preprint arXiv:2305.18811v2},
url = {https://arxiv.org/abs/2305.18811v2},
year = {2025},
}
```

Há projetos científicos que utilizam e citam o PyPOTS. Explore [pesquisas que citam ou utilizam PyPOTS](https://scholar.google.com/scholar?as_ylo=2022&q=%E2%80%9CPyPOTS%E2%80%9D&hl=en).

### Pesquisas relacionadas

- **[SAITS](https://doi.org/10.1016/j.eswa.2023.119619)** (ESWA 2023, mais de 1.000 citações): projeto de pesquisa que deu origem ao PyPOTS. Sua implementação original de imputação por autoatenção estabeleceu a base do código do PyPOTS.
- **[TSI-Bench](https://arxiv.org/abs/2406.12747)** (preprint arXiv 2024): Benchmark padronizado de imputação de séries temporais com 34.804 experimentos, 28 algoritmos e 8 conjuntos de dados sob diversas condições de ausência de dados. Repositório de código: [Awesome_Imputation](https://github.com/WenjieDu/Awesome_Imputation).
- **[Deep Learning for Multivariate Time Series Imputation: A Survey](https://doi.org/10.24963/ijcai.2025/1187)** (IJCAI 2025): taxonomia de métodos de imputação, ferramentas e direções de pesquisa.
- **[HELIX](https://openreview.net/forum?id=FN20iuPnEU)** (ICML 2026 Spotlight): identidades aprendíveis e síntese entre dimensões para imputação de séries temporais.
- **[End-to-End Learning for Partially-Observed Time Series with PyPOTS](https://doi.org/10.1145/3770855.3816470)** (KDD 2026, tutorial prático): fluxos de trabalho da preparação de dados e modelagem multitarefa até avaliação e integração de modelos personalizados. [Materiais do tutorial](https://pypots.com/events/KDD2026Tutorial/).

## ❖ Contribuições

Contribuições de pesquisadores, engenheiros e usuários são bem-vindas:

- **Novos modelos:** consulte os [critérios de inclusão](https://docs.pypots.com/en/latest/faq.html#inclusion-criteria) e use um template específico da tarefa (por exemplo, [imputação](https://github.com/WenjieDu/PyPOTS/tree/main/pypots/imputation/template)).
- **Correções e funcionalidades:** relate problemas reproduzíveis ou proponha melhorias via [GitHub Issues](https://github.com/WenjieDu/PyPOTS/issues).
- **Documentação e exemplos:** melhore tutoriais, documentação de API, exemplos e traduções.
- **Testes:** adicione testes de regressão para melhorar a confiabilidade e a reprodutibilidade.
- **Segurança:** relate vulnerabilidades de forma privada conforme [SECURITY.md](https://github.com/WenjieDu/PyPOTS/blob/main/SECURITY.md).

Antes de enviar um pull request, recomendamos ativar o [pre-commit](https://pre-commit.com/) no seu clone local para formatar e verificar automaticamente suas alterações:

```bash
pip install pre-commit
pre-commit install
```

Os hooks são executados automaticamente ao fazer um commit. Se um hook modificar arquivos, revise as alterações, adicione-as novamente à área de staging e refaça o commit. O GitHub CI verifica o linting e a formatação com Ruff mesmo que você não instale os hooks. Consulte o [guia de desenvolvimento](https://docs.pypots.com/en/latest/dev_getting_started.html#using-pre-commit) para mais detalhes.

Os colaboradores são reconhecidos na [página de colaboradores do GitHub](https://github.com/WenjieDu/PyPOTS/graphs/contributors), no [site do PyPOTS](https://pypots.com/about/#volunteer-developers) e nas notas de versão, quando aplicável. Siga nosso [código de conduta](https://github.com/WenjieDu/PyPOTS/blob/main/CODE_OF_CONDUCT.md).

Se o PyPOTS for útil para você, considere dar uma estrela ao repositório. Conheça as [instituições de nossos usuários](https://pypots.com/users/).
