PyPOTS (произносится «Pie Pots») — инструментарий Python с открытым исходным кодом для анализа временных рядов. Он предлагает **более 50 моделей и методов с унифицированными API** для восстановления пропусков, прогнозирования, классификации, кластеризации, обнаружения аномалий и обучения представлений. Он предназначен для реальных временных рядов, включая ряды с пропущенными значениями.

Временной ряд — это не сама лежащая в его основе система, а совокупность наблюдений за ней. Из-за присущих измерению и дискретизации ограничений реальные временные ряды по своей природе являются частичными наблюдениями: измеряемые переменные отражают лишь отдельные аспекты системы, наблюдения выполняются через дискретные, возможно нерегулярные интервалы, а некоторые измерения могут отсутствовать.

**Отсутствие наблюдения не обязательно означает отсутствие объекта. Частичная наблюдаемость — правило, а не исключение.**

Мы рассматриваем реальные временные ряды как **частично наблюдаемые временные ряды (Partially-Observed Time Series, POTS)**. С этой точки зрения моделирование временных рядов заключается прежде всего в изучении лежащей в их основе системы и её динамики по частичным наблюдениям. PyPOTS основан на этой философии и обеспечивает унифицированный анализ реальных временных рядов.

## ❖ Основные возможности

- **Поддержка нескольких задач:** восстановление пропусков, прогнозирование, классификация, кластеризация, обнаружение аномалий и обучение представлений в одном инструментарии.
- **Нативная поддержка пропусков:** модели, учитывающие пропуски, обучаются непосредственно на неполных рядах без предварительного восстановления значений.
- **Унифицированные API:** согласованные интерфейсы обучения и предсказания упрощают эксперименты и сравнение моделей.
- **Обширный каталог:** более 50 моделей и методов, включая классические подходы, глубокое обучение, модели на основе LLM и фундаментальные модели временных рядов (TSFM).
- **<a href="https://landscape.pytorch.org/?item=modeling--specialized--pypots"><img src="https://pypots.com/figs/misc/pytorch.svg" width="26px" align="center">PyTorch Ecosystem</a>:** PyPOTS построен на PyTorch и представлен в PyTorch Landscape.
- **Аппаратное ускорение:** CPU и GPU NVIDIA, обучение на нескольких GPU через PyTorch DataParallel и автоматическая смешанная точность для поддерживаемых моделей.
- **Гибкая работа с данными:** данные в памяти и отложенная загрузка из файлов HDF5.
- **Оптимизация гиперпараметров:** настройка моделей с помощью [Optuna](https://github.com/optuna/optuna).
- **Воспроизводимые исследования:** наборы данных, моделирование пропусков, стандартизованная предобработка и инструменты оценки в экосистеме.
- **Расширяемая архитектура:** модульные компоненты и стандартные шаблоны для интеграции новых алгоритмов.

## ❖ Установка

Для PyPOTS требуется Python 3.10 или новее. Пакет доступен в [PyPI](https://pypi.org/project/pypots/) и [Anaconda](https://anaconda.org/conda-forge/pypots). Подробные требования к зависимостям и окружению приведены в [руководстве по установке](https://docs.pypots.com/en/latest/install.html).

Выберите **один** из следующих способов установки в соответствии с вашим окружением. Команды обновления нужны только при наличии установленного PyPOTS.

**Вариант 1: pip (рекомендуется)**

```bash
pip install pypots
# Для обновления: pip install pypots --upgrade
```

**Вариант 2: Conda**

```bash
conda install conda-forge::pypots
# Для обновления: conda update conda-forge::pypots
```

**Вариант 3: Docker**

```bash
docker run -it --name pypots wenjiedu/pypots
```

Нажмите Ctrl-P, затем Ctrl-Q, чтобы отключиться, не останавливая контейнер. Для повторного подключения выполните `docker attach pypots`.

**Вариант 4: актуальный исходный код ветки main (может содержать ещё не выпущенные изменения)**

```bash
pip install https://github.com/WenjieDu/PyPOTS/archive/main.zip
```

## ❖ Использование

### Быстрый старт

Этот самостоятельный пример восстановления пропусков с помощью SAITS использует синтетические данные и не требует загрузки наборов данных. Входные данные имеют форму `(n_samples, n_steps, n_features)`, а пропуски обозначаются `NaN`.

```python
import numpy as np
from pypots.imputation import SAITS

# Создать синтетические ряды с пропусками
rng = np.random.default_rng(42)
X = rng.normal(size=(16, 24, 8)).astype(np.float32)
X[rng.random(X.shape) < 0.1] = np.nan
train_X, test_X = X[:12], X[12:]

# Инициализировать модель SAITS
model = SAITS(
    n_steps=24, n_features=8,
    n_layers=2, d_model=64, n_heads=4,
    d_k=16, d_v=16, d_ffn=128,
    epochs=2, device="cpu",
)
# Обучить модель
model.fit({"X": train_X})

# Восстановить пропуски в тестовом наборе
imputed_X = model.impute({"X": test_X})
print(imputed_X.shape)  # (4, 24, 8)
```

<summary><b>Показать пример восстановления пропусков с SAITS на PhysioNet2012:</b></summary>

``` python
import numpy as np
from pygrinder import calc_missing_rate
from benchpots.datasets import preprocess_physionet2012
data = preprocess_physionet2012(subset='set-a',rate=0.1) # Our ecosystem libs will automatically download and extract it
train_X, val_X, test_X = data["train_X"], data["val_X"], data["test_X"]
print(train_X.shape)  # (n_samples, n_steps, n_features)
print(val_X.shape)  # samples (n_samples) in train set and val set are different, but they have the same sequence len (n_steps) and feature dim (n_features)
print(f"We have {calc_missing_rate(train_X):.1%} values missing in train_X")
train_set = {"X": train_X}  # in training set, simply put the incomplete time series into it
val_set = {
    "X": val_X,
    "X_ori": data["val_X_ori"],  # in validation set, we need ground truth for evaluation and picking the best model checkpoint
}
test_set = {"X": test_X}  # in test set, only give the testing incomplete time series for model to impute
test_X_ori = data["test_X_ori"]  # test_X_ori bears ground truth for evaluation
indicating_mask = np.isnan(test_X) ^ np.isnan(test_X_ori)  # mask indicates the values that are missing in X but not in X_ori, i.e. where the gt values are

from pypots.imputation import SAITS  # import the model you want to use
from pypots.nn.functional import calc_mae
saits = SAITS(n_steps=train_X.shape[1], n_features=train_X.shape[2], n_layers=2, d_model=256, n_heads=4, d_k=64, d_v=64, d_ffn=128, dropout=0.1, epochs=5)
saits.fit(train_set, val_set)  # train the model on the dataset
imputation = saits.impute(test_set)  # impute the originally-missing values and artificially-missing values
mae = calc_mae(imputation, np.nan_to_num(test_X_ori), indicating_mask)  # calculate mean absolute error on the ground truth (artificially-missing values)
saits.save("save_it_here/saits_physionet2012.pypots")  # save the model for future use
saits.load("save_it_here/saits_physionet2012.pypots")  # reload the serialized model file for following imputation or training
```

## ❖ Экосистема PyPOTS

Добро пожаловать в кофейную вселенную PyPOTS! Наша экосистема вдохновлена приготовлением кофе: каждая библиотека играет свою роль в анализе временных рядов.

<a href="https://github.com/WenjieDu/TSDB">
    <img src="https://pypots.com/figs/pypots_logos/TSDB/logo_FFBG.svg" align="left" width="140" alt="TSDB logo"/>
</a>

👈 Наборы данных — наши кофейные зёрна, а наборы POTS — неполные зёрна. [Time Series Data Beans (TSDB)](https://github.com/WenjieDu/TSDB) упрощает загрузку общедоступных наборов временных рядов. Актуальный перечень наборов находится в репозитории.

<a href="https://github.com/WenjieDu/PyGrinder">
    <img src="https://pypots.com/figs/pypots_logos/PyGrinder/logo_FFBG.svg" align="right" width="140" alt="PyGrinder logo"/>
</a>

👉 [PyGrinder](https://github.com/WenjieDu/PyGrinder) перемалывает зёрна, моделируя пропуски. Он поддерживает все три механизма, определённые Rubin[^13], а именно MCAR (полностью случайные пропуски), MAR (случайные пропуски) и MNAR (неслучайные пропуски). Добавляйте искусственные пропуски одной строкой кода.

<a href="https://github.com/WenjieDu/BenchPOTS">
    <img src="https://pypots.com/figs/pypots_logos/BenchPOTS/logo_FFBG.svg" align="left" width="140" alt="BenchPOTS logo"/>
</a>

👈 Присаживайтесь на скамейку! [BenchPOTS](https://github.com/WenjieDu/BenchPOTS) предоставляет стандартизованные конвейеры предобработки для справедливой и воспроизводимой оценки алгоритмов в разных задачах.

<a href="https://github.com/WenjieDu/BrewPOTS">
    <img src="https://pypots.com/figs/pypots_logos/BrewPOTS/logo_FFBG.svg" align="right" width="140" alt="BrewPOTS logo"/>

## ❖ Цитирование PyPOTS

PyPOTS впервые был представлен на [семинаре MiLeTS в рамках KDD 2023](https://kdd-milets.github.io/milets2023/). При использовании PyPOTS в исследованиях цитируйте [статью об инструментарии](https://arxiv.org/abs/2305.18811v2).

```bibtex
@article{du2023pypots,
title = {{PyPOTS: A Python Toolkit for Data Mining on Partially-Observed Time Series}},
author = {Wenjie Du},
journal = {SIGKDD MiLeTS Workshop},
url = {https://arxiv.org/abs/2305.18811v1},
year = {2023},
}
```

```bibtex
@article{du2025pypots,
title = {{PyPOTS: A Python Toolkit for Machine Learning on Partially-Observed Time Series}},
author = {Wenjie Du and Yiyuan Yang and Linglong Qian and Jun Wang and Qingsong Wen},
journal = {arXiv preprint arXiv:2305.18811v2},
url = {https://arxiv.org/abs/2305.18811v2},
year = {2025},
}
```

Существуют научные проекты, использующие и цитирующие PyPOTS. Ознакомьтесь с [исследованиями, цитирующими или использующими PyPOTS](https://scholar.google.com/scholar?as_ylo=2022&q=%E2%80%9CPyPOTS%E2%80%9D&hl=en).

### Связанные исследования

- **[SAITS](https://doi.org/10.1016/j.eswa.2023.119619)** (ESWA 2023, более 1 000 цитирований): исследовательский проект, давший начало PyPOTS. Его оригинальная реализация восстановления пропусков на основе механизма самовнимания заложила фундамент кодовой базы PyPOTS.
- **[TSI-Bench](https://arxiv.org/abs/2406.12747)** (препринт arXiv 2024): Стандартизованный бенчмарк для восстановления пропусков во временных рядах с 34 804 экспериментами, 28 алгоритмами и 8 наборами данных при различных условиях пропусков. Репозиторий кода: [Awesome_Imputation](https://github.com/WenjieDu/Awesome_Imputation).
- **[Deep Learning for Multivariate Time Series Imputation: A Survey](https://doi.org/10.24963/ijcai.2025/1187)** (IJCAI 2025): классификация методов восстановления пропусков, инструментариев и направлений исследований.
- **[HELIX](https://openreview.net/forum?id=FN20iuPnEU)** (ICML 2026 Spotlight): обучаемые идентификаторы и межразмерностный синтез для восстановления пропусков.
- **[End-to-End Learning for Partially-Observed Time Series with PyPOTS](https://doi.org/10.1145/3770855.3816470)** (KDD 2026, практический туториал): рабочие процессы от подготовки данных и многозадачного моделирования до оценки и интеграции собственных моделей. [Материалы туториала](https://pypots.com/events/KDD2026Tutorial/).

## ❖ Вклад в проект

Мы приветствуем вклад исследователей, инженеров и пользователей:

- **Новые модели:** ознакомьтесь с [критериями включения](https://docs.pypots.com/en/latest/faq.html#inclusion-criteria) и используйте соответствующий задаче шаблон (например, [восстановление пропусков](https://github.com/WenjieDu/PyPOTS/tree/main/pypots/imputation/template)).
- **Исправления и функции:** сообщайте о воспроизводимых проблемах и предлагайте улучшения через [GitHub Issues](https://github.com/WenjieDu/PyPOTS/issues).
- **Документация и примеры:** улучшайте учебные материалы, документацию API, примеры и переводы.
- **Тестирование:** добавляйте регрессионные тесты для повышения надёжности и воспроизводимости.
- **Безопасность:** сообщайте об уязвимостях конфиденциально согласно [SECURITY.md](https://github.com/WenjieDu/PyPOTS/blob/main/SECURITY.md).

Вклад участников отмечается на [странице участников GitHub](https://github.com/WenjieDu/PyPOTS/graphs/contributors), [сайте PyPOTS](https://pypots.com/about/#volunteer-developers) и, при необходимости, в примечаниях к выпускам. Соблюдайте [кодекс поведения](https://github.com/WenjieDu/PyPOTS/blob/main/CODE_OF_CONDUCT.md).

Если PyPOTS полезен вам, поставьте звезду репозиторию, чтобы другие могли его обнаружить. Посмотрите [организации наших пользователей](https://pypots.com/users/).

## ❖ Сообщество

Присоединяйтесь к сообществу PyPOTS, чтобы задавать вопросы, обсуждать исследования, делиться отзывами и сотрудничать:

- [Discord](https://discord.gg/DXpCTdrvCE): обсуждения, вопросы и разработка.
- ~~Slack~~ (закрыт): мы перешли в Discord, поскольку бесплатный тариф Slack не хранит историю переписки бессрочно.
- [LinkedIn](https://www.linkedin.com/company/pypots): официальные объявления и новости.
- [WeChat (официальный аккаунт)](https://mp.weixin.qq.com/s/X3ukIgL1QpNH8ZEXq1YifA): подпишитесь на аккаунт, чтобы получить QR-код группы сообщества.
- [GitHub Issues](https://github.com/WenjieDu/PyPOTS/issues): сообщения об ошибках и запросы функций.

Мы рады отзывам и идеям всех, кто работает с реальными временными рядами.
